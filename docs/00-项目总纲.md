## 1. 项目是什么

2D 斯诺克（桌球）走位教学工具，Windows 桌面端。

核心内容模型：

**彩球 × 袋口 × 进袋方式 → 一条打法**
含：力度、瞄准方法、低杆/高杆走位补偿、补充说明 + 3 张图（击球点 / 蓝点 / 路线）

另有「进阶系列」：直线 / 翻袋 / 弧线 / 破局 / 其他，结构类似但只有 1 张图。

**本项目是全新重写**，从旧 WPF 版（`E:\wpf\wpf\SnookerApp\Snooker_2D`）重构而来：
- 后端：MySQL + Excel 双写 + 自制同步 → **Supabase**
- 前端：WPF + Prism + HandyControl → **Electron + Vue3 + TypeScript + Element Plus**
- UI：视觉重做，保留布局骨架与交互逻辑

## 4. 目标架构

```
Electron 主进程
  ├─ 窗口管理（无边框、最小化/关闭、单实例）
  ├─ nativeTheme（跟随系统主题）
  ├─ safeStorage（加密存 refresh token）
  └─ 本地文件读写（userData 下的 JSON / 图片缓存）
        ↕ IPC
渲染进程（Vue3）
  ├─ 视图层（Element Plus）
  ├─ Pinia Store（auth / dataset / theme / ui）
  └─ 共享层 src/shared
       ├─ api/     supabase-js 封装、RPC 调用
       ├─ auth/    登录、刷新、登出
       ├─ sync/    快照同步（版本比对 + 下载 + 原子替换）
       └─ media/   图片缓存
        ↕ HTTPS
Supabase
  ├─ Postgres（表 + RLS + RPC）
  ├─ Auth（GoTrue）
  └─ Storage（图片 + 图片变换）
```

- **读**：永远读本地缓存（秒开、断网可用）
- **同步**：启动时比对 `dataset_version`，不同则全量下载，`temp` 文件 + 原子 rename 替换
- **写**：必须在线，走 PostgREST / RPC
- **评论**：不进快照，按需分页查询
- **作者状态**：随快照下发 `author_deleted`（停用/恢复账号时**显式 bump** `dataset_version`）；评论的作者状态由评论 RPC 实时 join 返回
