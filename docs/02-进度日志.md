- **遇到的坑**（**重要，都是实测才发现的**）：
  - **`p_update` 策略允许自我提权**：`using (id = auth.uid())` 只限行不限列，普通用户 `PATCH /profiles?id=eq.<自己> {"role":"admin"}` 就能变管理员，先审后发直接失效。已加 `guard_profile_role` 触发器
  - **guard 第一版写错了**：条件里 `not is_admin()` 在服务端上下文（`auth.uid()` 为 null）恒为真，导致**连 SQL Editor 都设不了管理员**——`update profiles set role='admin'` 静默回滚。改成 `auth.uid() is not null and not is_admin()` 才对
  - **`create function` 默认 `grant execute to public`**：不 revoke 的话未登录可 `POST /rest/v1/rpc/get_dataset_snapshot` 拉全量数据。9 个函数全部显式 `revoke from public, anon` 再 `grant to authenticated`
  - **revoke `is_admin` from anon 会误伤读表**：策略表达式里调用 `is_admin()`，anon 无执行权时未登录读 `balls` 报 `42501 permission denied for function is_admin` 而不是空数组。只能给 anon 放行（函数恒 false，不泄露数据）
  - **`bump_dataset_version` 必须 security definer**：`dataset_meta` 有 RLS 无写策略，普通函数在管理员绕过 RPC 直接 `PATCH /balls` 时会因更新 `dataset_meta` 被拒而使整条 update 失败
  - `revoke execute ... from public, anon` 后 advisors 仍会报 `authenticated_security_definer_function_executable` 9 条——这是 D12 的必然结果，**不要试图清零**
- **遗留问题**：
  - 数据库密码仍未拿到（T0.5 备份前必须去 Dashboard 重置）
  - 表里还没有业务数据，`balls`/`advanced`/`comments` 全 0

### 2026-10-31 · T3.3 修复：用户实测反馈的 3 个问题（完成）

  3. 进球方式用「可输入可选」时，自定义输入**只有按回车**才生效；按 Tab / 点别的输入框会丢失
- **改法**：
  1. **预览**：`onPick` 里从「改 `images[slot].preview` 字段」改成**整个对象替换** `images[slot] = { file, preview, path }` —— 同一 tick 内连续赋值 + `validateField` 触发的重渲染下，嵌套字段变更在部分时序里不会立刻反映到视图；换新对象必然触发依赖
  2. **文案与限制**：`accept` 收窄为 `image/png,image/jpeg,image/webp`；`onPick` 校验类型与体积（**单张 ≤ 5 MB**，超限给具体大小）；提示改为「支持 JPG / PNG / WebP，单张 ≤ 5 MB，保存时自动转 WebP」
  3. **进球方式**：`el-select + filterable + allow-create` → **`el-autocomplete`**。EP 的 `allow-create` 只在回车/点选项时写 model，失焦会清空输入；`el-autocomplete` 的 v-model 直接绑输入框文本，失焦天然保留，语义就是"可输入可选"
- **验证**（用独立 userData 起的第二个实例 + CDP，**不动用户正在用的窗口**）：
  - 预览：选图后 **120ms 内** `.image-preview img` 已出现、`src` 是 `blob:`、`--empty` 类已移除、不再显示"未选择"
  - 限制：`accept` 三个 input 都是 `image/png,image/jpeg,image/webp`；提示文案三处一致；传 `.txt` → 拒收 + 「只支持 JPG / PNG / WebP 图片」，预览框保持空
  - 失焦：输入「用户自定义方式XYZ」→ 直接 focus 到 textarea（等价 Tab）→ 输入框里**值仍在**
- **改了哪些文件**：`src/renderer/src/components/BallFormDialog.vue`、`docs/02`

### 2026-10-31 · 修复：选图预览显示破图（CSP 漏了 blob:）

- **用户截图反馈**：选了图之后预览框里是**破图图标 + alt 文本**「击球点图片」，不是图片本身
- **根因**：预览用 `URL.createObjectURL()` 生成 `blob:` 地址，而 `index.html` 的 CSP 是 `img-src 'self' data: https://*.supabase.co` —— **没有 `blob:`**，`<img>` 直接被拦成破图。控制台只有一条 CSP 报错，很容易误判成"组件没更新"
- **修法**：`img-src` 补 `blob:`
- **为什么上一轮没抓到（教训）**：上一轮验证只断言了「`.image-preview img` 存在 + `src` 以 `blob:` 开头」，**没有断言图片真的解码成功**。元素存在 ≠ 图片加载成功，CSP 拦截恰恰是"元素在、图不出来"。以后验证图片一律加 `img.complete && img.naturalWidth > 0`
- **复验**：`complete: true`、`naturalWidth: 100`、`naturalHeight: 100`、`scheme: blob`、**CSP violations: []**；截图确认预览框里是真实球图
- **改了哪些文件**：`src/renderer/index.html`、`docs/02`

### 2026-11-03 · T5.3 流量实测（完成，阶段 5 收口）

- **实测**：
  - **20 条（验收项）**：60 个图位 → **45 张唯一图**（复用去重 25%）；下载 **605,734 B = 0.58 MB**，平均 13.4 KB/张；加快照 141 KB = **0.72 MB**（目标 < 2 MB ✅）；60 张并发加载 1.06 s
  - **全量（校准配额表）**：435 个图位 → **328 张唯一图**，**6.93 MB**，平均 **21.6 KB/张**；100 人首访 **0.68 GB**（免费额度 5 GB 的 14%）；328 张分批 12 并发加载 19.1 s
- **结论**：配额红线不变（原写 316 张 / 6.7 MB / 0.67 GB，实测 328 / 6.93 / 0.68，差异来自数据增长）。缓存 + 懒加载后真实月流量只会更低。
